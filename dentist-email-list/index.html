How we build it

How Our Dentists Email Database Is Sourced and Kept Current

Our dentist email database is built in 5 stages, and a record only moves forward once it clears the stage before it. A closed practice or a dead inbox gets caught early, and the full file goes back through the last stage every 90 days. Records that fail a stage are fixed or removed before they ever reach a buyer.

01

Pull From Official Registries

US records start from the federal NPI registry, and others from national dental registers.

02

Confirm the License

Each dentist is checked against state or national dental board license records.

03

Link Dentist to Practice

Each dentist is tied to a current practice and any DSO it belongs to.

04

Check and Tag Each Inbox

Each email passes domain and mailbox checks and gets an inbox type tag.

05

Clear Out Retirees and Opt-Outs

Retired dentists drop out and new ones come in. Opt-outs stay suppressed.
